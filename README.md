# 💰 [Coin Keeper](https://coin-keeper-zeta.vercel.app/)

**Coin Keeper** — это приложение для учёта доходов и расходов, которое позволяет контролировать финансы, распределять транзакции по категориям и анализировать финансовую активность с помощью наглядных графиков. Проект реализован как полноценное frontend-приложение с backend-частью на **Supabase**.

## 🚀 Функциональность

* 🔐 Регистрация и авторизация пользователей
* ➕ Добавление и удаление транзакций доходов и расходов
* 🏦 Управление счетами: добавление, редактирование и удаление
* 🗂️ Управление категориями транзакций
* 📊 Графики для анализа **ежемесячных доходов и расходов**
* 🔄 Сортировка счетов по дате создания и балансу
* ☁️ Хранение данных и аутентификация через Supabase

## 🛠️ Технологии

* **React** — компонентный подход и управление состоянием
* **TypeScript** — строгая типизация и надежность кода
* **Vite** — быстрый dev-сервер и сборка
* **Tailwind CSS** — утилитарная стилизация интерфейса
* **shadcn/ui** — готовые и кастомизируемые UI-компоненты
* **Supabase** — backend-as-a-service (Auth, Database, API)
* **ESLint + Prettier** — контроль качества и форматирования кода

## 🎯 Цель проекта

Проект **Coin Keeper** создан для:

* разработки **полноценного SPA-приложения** с backend-интеграцией;
* практики работы с **Supabase** (аутентификация, CRUD-операции, запросы);
* изучения и применения **shadcn-ui** в реальном проекте;
* улучшения архитектуры React-приложений и работы с финансовыми данными.
